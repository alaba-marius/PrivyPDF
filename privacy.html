Privacy model

Private by architecture, not by promise

PrivyPDF can't see your documents because it has nowhere to send them. Here's exactly how that works.

No uploads

There is no server endpoint that accepts files.

Network locked down

CSP blocks connections to every other origin.

No tracking

No analytics, cookies, fingerprinting or third-party scripts.

Self-hosted engines

pdf.js, pdf-lib and fonts are served from this site.

The life of a file

  1. You choose a file or drop it on the page. Your browser reads it into the tab's memory as raw bytes.
  2. pdf.js renders pages to canvases in a background Web Worker, all on your machine.
  3. When you edit, PrivyPDF only changes a lightweight list of pages. The original bytes stay untouched.
  4. On download, pdf-lib assembles a new PDF in memory and your browser saves it to disk.
  5. Close or reload the tab and everything is discarded.

When you drop a file on the home page, it's handed to the editor through your browser's local IndexedDB storage and deleted the moment the editor opens it. It never leaves your device.

The Content Security Policy

Every page enforces this policy in the browser. connect-src 'self' means the browser itself will refuse any request to another server, even if a bug or a malicious dependency tried to make one.

default-src 'self'; script-src 'self' 'wasm-unsafe-eval'; style-src 'self' 'unsafe-inline'; img-src 'self' blob: data:; font-src 'self'; connect-src 'self'; worker-src 'self' blob:; object-src 'none'; form-action 'none';

Verify it yourself

  1. Open the editor, then open DevTools (F12 or Cmd+Option+I).
  2. Go to the Network tab and click the clear button.
  3. Open a PDF, reorder some pages, and download the result.
  4. You'll only see requests to this site for the app's own assets, such as a font file pdf.js needs. Nothing contains your document and nothing goes to another server.
  5. For extra proof, turn off Wi-Fi after the editor loads. Everything keeps working.

The editor also shows a live counter of requests to other origins. It should always read zero.

Honest limitations

  • Password-protected PDFs aren't supported yet. Unlocking will arrive in a later release, also on-device.
  • Very large files are limited by your device's memory, not by us.
  • Browser extensions you install can read page content. That's outside any website's control.
