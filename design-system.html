Design system

Dev-only style guide for the PrivyPDF design system in css/theme.css. Every component is prefixed with ds- so it never collides with main.css or editor.css. This page is not shipped to customers; it is consumed by the D2 (landing, privacy, shared nav/footer) and D3 (editor) remodels. It loads only css/theme.css and contains no inline styles, no scripts, and no external requests.

Components

Every ds- component in default, hover (ds-fs--hover), focus (ds-fs--focus) and disabled (ds-fs--disabled) states, on white. A Studio Black band section follows with the dark-suited components. Forced-state classes are static stand-ins for :hover / :focus-visible / :disabled; the real states also work natively in the browser.
