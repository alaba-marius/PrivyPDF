FAQ

Questions, answered

Are my files really never uploaded?

Yes. PrivyPDF has no backend that accepts files. Documents are read with the browser's File API, processed in memory with pdf.js and pdf-lib, and saved back with a local download. A strict Content Security Policy blocks connections to any other origin.

Do I need an account?

No. There are no accounts, logins, cookies or analytics. Open the editor and start working.

Does it work offline?

Once the page has loaded, every tool works without a connection. Full installable offline mode is coming in a later release.

What happens to my file when I close the tab?

It's gone. Files only live in the tab's memory and are discarded when you close or reload it.

Is there a file size limit?

Only your device's memory. Files up to a few hundred megabytes work well on modern laptops. Pages render lazily as you scroll so large documents stay responsive.
