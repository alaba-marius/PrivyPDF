Questions, answered

Are my files really never uploaded?

Yes. PrivyPDF has no backend that accepts files. Your document is read into this tab's memory and processed on your device. A strict CSP blocks the browser from connecting to any other origin.

Do I need an account?

No. There are no accounts, logins, cookies or trackers.

Does it work offline?

Not yet. The pages load while you're online; offline use is planned for a later release.

What happens when I close the tab?

Your file is gone. Files live only in this tab's memory and are discarded when you close or reload it.

Is there a file size limit?

Only your device's memory. Large documents are limited by what your device can hold, not by any limit we set.
